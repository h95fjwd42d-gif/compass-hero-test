# v9.10.7 変更前・変更後・理由（2026-11-24）

## 変更した場所
- 新規 `practical-adaptive.js`：回答に応じて質問を選ぶエンジン（106問プール・30問回答）。
- `app.js`：新エンジンを使う実戦診断画面、回答履歴を質問IDで復元、未経験や複数ロールに配慮した説明。
- `question-intents.js`：新しいメタ質問・好み質問・能力質問の意図と採点の違いを説明。
- `index.html`：新スクリプト読み込みとバージョン表記。
- `test-v9107-adaptive.js`、`QUESTION_POOL_106.csv`、`README_V9107.txt`、調査資料を追加。

## 変更前 → 変更後 → 理由
1. 実戦30問は常に同じ → 106候補から30問を動的に選択 → 同じ調査項目の過剰な繰り返しを減らし、回答によって必要な質問を優先するため。
2. ロール経験を最初に4問固定 → 経験者は4ロールをすべて確認し、初心者は4ロールの『試したい』を確認 → 未経験を苦手と誤判定しないため。
3. 複数ロールを選択できないような印象 → どのロールも除外せず、上位候補には各ロールの人物も残す → 複数ロールの人の適性を見失わないため。
4. 一人のキャラしか使わない回答者への案内が不足 → 使用キャラ数を最初の質問で確認し、未経験は無得点かつ減点なし → 使っていないだけで『苦手』と判定しないため。
5. ほぼ初心者は操作質問に回答しにくい → 初心者には『試してみたい戦い方』の質問を多く出す。技術と好みの得点は別の強さで評価 → 未経験でも参加でき、実技ができると誤認しないため。
6. HA・HSの詳細は研究βに隔離 → HA・HS関連の質問を候補として追加。ただし特定のHAタメ・HS直接妨害は個別監査に一致するヒーローのみ小さく評価 → 無関係な能力に誤加点しないため。
7. 旧バージョンと回答履歴が混在する懸念 → 新しいローカル保存キーを使用 → 固定30問セッションと動的30問セッションを混同しないため。
8. 結果を操作適性だけで表示 → 初心者の結果は『試したい戦い方から探す』と明示 → 根拠が主に興味の場合に技能を保証しないため。

## 大事な限界
- 30問の中身が変わるため、v9.10.6の得点や友達の旧30回答との直接比較はできない。
- 自動検証は動作・安全性・出題分岐を評価したものであり、実際の推薦精度の改善は未証明。
- 参考得点は勝率ではない。プレイ経験が少ない場合は結果の根拠を強調して表示する。
- 最新のゲームバランス調整や全ヒーローのHA・HS詳細仕様はこの変更で再検証していない。
