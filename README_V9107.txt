# HERO FINDER v9.10.7 適応型30問 ベータ

このZIPの index.html をPCのChromeで開くか、テスト用GitHub Pagesのルートに配置してください。元の本番サイトへの上書きは禁止。

主な変更：実戦診断の質問候補106問、実際に回答するのは30問。最初の2問でプレイ頻度と使用キャラの幅を確認し、その後の出題経路を調整します。ロールは1種類に限定せず、未経験を苦手として減点しません。

初心者は今後試したい戦い方の質問が中心となり、結果は実技実測ではなく興味に近い候補として表示されます。どの構成でも基本的には最初の2問＋残り28問です。

旧固定30問とのデータの照合のため、元の practical.js は変更していません。新規の practical-adaptive.js だけが画面で使われます。

推奨テスト（3ケース）
A. 普段複数ロールを使う人：得意なロールを複数『できる』と答え、それぞれの順位が不自然に排除されないか確認。
B. ほぼ1キャラ中心の人：知らないロールやカードは『未経験』にし、順位が過度に変にならないか確認。
C. 最近ほとんど遊んでいない人：最初の回答で『ほとんど遊んだことがない』を選び、興味から回答できるか確認。

確認する情報：各テストの『回答した30問の一覧』『上位5人』『違和感があるヒーローと理由』。可能ならスクリーンショット。

未実装：ライト診断20問化、性格TOP5、隠しキャラ好み診断。実戦の推薦精度が上がったとまでは断定できません。
